5.1

Casebeschrijving

Vue.js JavaScript REST API .NET Backend JWT Auth GitHub Flow 8 studenten · PXL

Tijdens Werkplekleren 2 werkten we als team van 8 PXL-studenten aan een volwaardige webapplicatie voor het beheer van een racecompetitie. Het team bestond uit een unieke mix van opleidingen: 3 studenten Graduaat Programmeren, 4 studenten DVO Design en 1 student DVO Web. Die samenwerking tussen verschillende disciplines zorgde voor een realistische, professionele projectomgeving.

De applicatie moest verschillende stakeholders bedienen: teammanagers die racers konden beheren, admins die scholen, teams en evenementen konden aanmaken en opvolgen, en gebruikers die merchandise konden bekijken en bestellen. De kern van het systeem draaide rond een evenementenplanner waarmee races en sub-evenementen gepland en opgevolgd konden worden.

Technisch bestond het project uit een Vue.js front-end en een .NET back-end met een REST API. Authenticatie verliep via JWT-tokens waarbij de rol van de ingelogde gebruiker (admin, teammanager, racer) bepaalde welke functionaliteiten zichtbaar en toegankelijk waren. De front-end communiceerde volledig via een centrale API-module met de back-end, waardoor de applicatie schaalbaar en onderhoudbaar bleef.

De samenwerking verliep via GitHub met feature branches, pull requests en code reviews. We maakten gebruik van een agile aanpak waarbij we regelmatig afstemden met de begeleidende lectoren. De studenten Design zorgden voor de visuele richting, terwijl de programmeurs de implementatie verzorgden — een taakverdeling die ik als bijzonder leerrijk ervaarde.

Het eindresultaat was een werkende full-stack applicatie met: een login- en registratiesysteem, een dashboardomgeving voor admins, merchandise- en orderbeheer, team- en racerbeheer, een evenementenplanner met kalenderweergave, en een profielpagina voor individuele gebruikers.

5.2

Mijn aandeel

Mijn bijdrage was volledig gericht op de front-end van de applicatie (Vue.js).

🛍️

MerchView & OrderOverview

Tab-gebaseerde merchandise pagina. Admins voegen producten toe via een formulier met live fotopreview en veldvalidatie. Orders worden overzichtelijk in een aparte tab weergegeven. Communicatie verloopt via REST API-calls.

👥

MyTeamView — Flip Cards

Interactieve teampagina met flip cards die bij klikken omdraaien en gedetailleerde info tonen. Inclusief sortering op voornaam, achternaam en e-mail, en paginatie voor grote datasets. Racers toevoegen/verwijderen via PUT-requests.

🔧

Herbruikbare UI-componenten

Bibliotheek van herbruikbare componenten: BaseInput, BaseButton, BaseSelect. Elk component ondersteunt props voor size, label, placeholder en type — uniforme look-and-feel zonder code-duplicatie.

🌐

API-integratie & Sessiebeheer

Centrale Api.js utility met automatische JWT-header-injectie vanuit Session.js. Correcte foutafhandeling bij mislukte requests. Elk component kan de API aanspreken zonder eigen autorisatielogica.

📐

Responsieve Styling & UX

Scoped CSS met donker kleurpalet en neongroene accentkleur passend bij het sportieve thema. Responsieve grid-layouts via media queries. Hover-animaties, transitions en duidelijke visuele feedback.

🧭

Routing & Views

Implementatie van views via Vue Router met rolgebaseerde toegangscontrole. Enkel de correcte views zijn toegankelijk voor de juiste gebruikerssegmenten (admin, teammanager, racer).
